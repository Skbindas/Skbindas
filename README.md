## About

I'm **Suhaib Choudhary**, an AI-assisted product builder focused on turning new technical capabilities into useful software.

I work across **AI products, browser automation, Chrome extensions, developer tools, and practical web/software experiments**. My workflow is simple:

> **Spot a new capability → find a painful workflow → prototype fast → test it → ship what is useful.**

I care more about **useful products and real proof-of-work** than collecting ideas.

## Current Mindset

I don't want to build yesterday's viral product six months late.

I'm building a repeatable habit:

**new signal → real problem → narrow solution → fast prototype → user feedback → useful software**

That is the loop.

## Beyond Code

**AI × software products × automation × distribution**

The goal is not to build more software for the sake of it.

The goal is to build **software people are genuinely glad exists.**
